# Luminara AI

Luminara AI is a transparent RAG knowledge-base platform for teams that need answers grounded in their own documents.

It turns PDFs, internal docs, policies, product notes, and technical references into a searchable AI workspace with citations, vector search, and retrieval trace.

## Product Vision

Most AI document tools feel like a black box. Luminara AI is designed around evidence.

Every answer should show:

- which sources were used
- which document chunks were retrieved
- how relevant each source was
- when the knowledge base does not contain enough information

## Core Capabilities

- Document upload and indexing
- Text extraction from knowledge files
- Chunking with metadata
- Embedding generation
- Vector search
- Grounded AI answers
- Citations and source snippets
- Retrieval trace for transparency

## Target Role

This project is built as a portfolio piece for AI Builder / Fullstack roles.

It demonstrates practical experience with:

- RAG architecture
- embeddings
- vector databases
- document processing
- AI API integration
- backend service design
- modern fullstack product UI

## Planned Stack

- Frontend: Next.js, React, TypeScript
- Styling: Tailwind CSS
- Backend: FastAPI, Python
- Vector database: Qdrant
- AI: OpenAI embeddings and chat models
- Deployment: Docker Compose
